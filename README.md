# Analyse des Salaires Data Science 2023

## Dataset

**Source:** [Data Science Salaries 2023 - Kaggle](https://www.kaggle.com/datasets/arnabchaki/data-science-salaries-2023)

Le dataset contient 3755 observations sur les salaires dans le domaine de la Data Science à travers 72 pays.

## Application

Application Streamlit d'analyse interactive des salaires avec :

- **Métriques clés** : salaire moyen, médiane, nombre d'employés et de postes
- **Distribution** : histogrammes et box plots des salaires
- **Analyse par rôles** : top 10 des postes les mieux payés et salaires par expérience
- **Analyse géographique** : comparaison des salaires par pays
- **Télétravail** : impact du remote sur les salaires et corrélations
- **Filtres avancés** : par expérience, taille d'entreprise et ratio de télétravail

## Installation

```bash
pip install pandas streamlit plotly kagglehub
```

## Lancement

```bash
streamlit run application.py
```
